Exposome Maps

View the inventory of data used by epidemiological studies in the ExposomeNL and EXPANSE projects. For background on our conceptualisation of the exposome and its categorisation into four dimensions, see these openly accessible publications:

  • The exposome and health: Where chemistry meets biology
  • Developing the building blocks to elucidate the impact of the urban exposome on cardiometabolic-pulmonary disease

Using the map

  • Pick a layer in the panel on the right; it is shown straight away for its most recent date.
  • Use the date control (or the arrows) to change the date, and the slider to change transparency.
  • Click anywhere on the map to see the value at that location.
  • Data were reprojected from their original coordinate reference system for display, so values on the map may differ slightly from the source data because of interpolation.

Data request

To request access to any data layer, complete the Data access request form and send it to expanse@uu.nl.

All data access and publication proposals are assessed on:

  1. scientific rigour of the analyses;
  2. the appropriate project group;
  3. overlap with other known analyses using the platform.
